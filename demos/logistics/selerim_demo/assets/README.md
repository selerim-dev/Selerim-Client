# Local assets

The WOFF2 files reuse the parent Selerim website's Latin font bundles:

- Inter Tight variable: https://fonts.google.com/specimen/Inter+Tight
- Instrument Serif, normal and italic: https://fonts.google.com/specimen/Instrument+Serif

Both are distributed under the SIL Open Font License 1.1. Their license notices are included alongside the fonts. The browser loads these files from the demo server; no font request goes to a third party.

`workspace.js` contains progressive enhancement only. All review and approval actions continue to use server-rendered pages and POST forms.
